## Server Components
In the Next.js app/ router, components are Server Components by default. You do not write 'use server' for a normal Server Component. Pages and layouts are server by default. Server Components are good for data fetching, accessing databases/secrets, reducing browser JavaScript, and improving initial load performance.

```javascript
// app/dashboard/invoices/page.tsx
// Server Component by default
import { db } from '@/db/drizzle';

export default async function Page() {
  const invoices = await db.query.invoices.findMany();

  return <InvoicesTable invoices={invoices} />;
}
```
This runs on the server. The browser does not receive your DB code.
